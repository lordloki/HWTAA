# Hybrid Windowed Temporal Antialiasing (HWTAA)

Temporal antialiasing and upscaling for the eevee-game renderer of UPBGE. Moving pixels are
reconstructed from a ring of the raw jittered samples of the last N frames, each moved exactly
once to the current frame and accepted by object identity; pixels at rest keep a recursive
history. Details, results and limitations in the paper.

| | |
|---|---|
| `en/hwtaa.pdf` | Paper (English) |
| `es/hwtaa_es.pdf` | Paper (Spanish) |
| `bench/` | Evaluation bench: runs the production shaders on the test scenes (see `bench/README.md`) |
| `figures/`, `tables/` | Generated by the bench scripts; do not edit |
| `refs.bib` | References of both papers |

Rebuild everything (about 25 minutes, no GPU needed): `bench/run_all.sh`.
Papers only: `latexmk -pdf` in `en/` or `es/`.
